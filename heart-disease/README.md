Description

The Heart Disease dataset contains clinical and diagnostic data used to predict the presence of heart disease in patients. It is widely used in machine learning and statistical analysis for training, testing, and validating classification models.

Dataset Content

Each row corresponds to a patient with various clinical measurements and test results.

Column	Description	Type

age	Patient’s age in years	Numerical  

sex	Patient’s sex (1 = male, 0 = female)	Categorical (binary)  

chest_pain_type	Type of chest pain (4 categories)	Categorical

resting_bp_s	Resting blood pressure (in mm Hg)	Numerical

cholesterol	Serum cholesterol level (mg/dl)	Numerical

fasting_blood_sugar	Fasting blood sugar > 120 mg/dl (1 = true, 0 = false)	Categorical (binary)

resting_ecg	Resting electrocardiographic results	Categorical

max_heart_rate	Maximum heart rate achieved during exercise test	Numerical

exercise_angina	Exercise induced angina (1 = yes, 0 = no)	Categorical (binary)

oldpeak	ST depression induced by exercise relative to rest	Numerical

st_slope	Slope of the peak exercise ST segment	Categorical

target	Presence of heart disease (1 = yes, 0 = no)	Categorical (binary)


**Objective**

The main goal is to develop predictive models capable of diagnosing the presence of heart disease based on patients’ clinical data.

Recommended Usage

Exploratory data analysis (EDA)

Data preprocessing and cleaning

Predictive modeling (supervised classification)

Model evaluation (accuracy, recall, F1-score, AUC)

Statistical visualizations
