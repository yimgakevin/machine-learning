This folder contains all notebooks, scripts, resources, and projects related to Deep Learning.
The goal is to explore modern architectures, essential concepts, and practical applications of deep neural networks.

Folder Structure
📂 1. Notebooks

Jupyter notebooks covering various deep learning topics:

Artificial Neural Networks (ANN)

Convolutional Neural Networks (CNN)

Recurrent Networks (RNN, LSTM, GRU)

Autoencoders

Transfer learning (VGG, ResNet, EfficientNet, etc.)

Fine-tuning on custom datasets

GPU-based training on Google Colab

📂 2. Python Scripts

Python scripts for:

Dataset preprocessing

Building and training neural network models

Evaluation and visualization of results

Loading and running inference on trained models

3. Datasets

Links or structured folders containing:

Training, validation, and testing images

Class-organized datasets

Label files and configuration scripts

🔧 Technologies Used

Python

TensorFlow / Keras

PyTorch

NumPy, Pandas, Matplotlib

Scikit-learn

Google Colab (GPU/TPU)
