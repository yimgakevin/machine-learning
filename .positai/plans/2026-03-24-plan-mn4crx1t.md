## Approche

### Style uniforme
Utiliser un **bandeau cohérent** pour tous les modules, avec le format suivant :

```r
tags$div(
  style = "background: linear-gradient(135deg, #f0f8ff 0%, #e8f4f8 100%);
           border-left: 4px solid #008DC9; border-radius: 6px;
           padding: 15px 20px; margin-bottom: 15px;",
  tags$h4(style = "margin:0 0 8px 0; color:#008DC9;",
          icon("icon-name"), "Titre du module"),
  tags$p(style = "margin:0; color:#555; font-size:13px; line-height:1.5;",
         "Description accessible en 2-3 phrases.")
)
```

### Descriptions prévues

| Module | Description prévue |
|--------|-------------------|
| **Exploration** | Découvrez la structure de vos données : aperçu, types de variables, valeurs manquantes et distributions. Point de départ recommandé avant toute analyse. |
| **Univariée** | Analysez une variable à la fois : histogrammes, boîtes à moustaches, statistiques descriptives. Utile pour comprendre la distribution de chaque indicateur. |
| **Bivariée** | Étudiez la relation entre deux variables : croisements, corrélations, tests d'association. Permet de détecter des liens entre facteurs. |
| **Tableau descriptif** | Générez un tableau récapitulatif de vos indicateurs selon les standards OMS : moyennes, écarts-types, intervalles de confiance par groupe. |
| **Inférentielle** | Tests statistiques pour vérifier si les différences observées sont significatives : t-test, ANOVA, chi², corrélations, avec vérification des hypothèses. |
| **Réduction de dimension** | Simplifiez des données complexes avec l'ACP ou l'AFC. Identifiez les axes principaux de variation dans vos données multivariées. |
| **Clustering** | Regroupez automatiquement vos observations en profils similaires : K-means, CAH, DBSCAN. Utile pour identifier des sous-populations. |
| **Indicateurs OMS/PAM** | Calculez les indicateurs nutritionnels standardisés : GAM, SAM, FCS, HDDS, rCSI selon les protocoles OMS et PAM. |
| **Épidémiologie** | Mesures d'association épidémiologiques : Odds Ratio, Risque Relatif, analyses multi-exposition, test de tendance Cochran-Armitage et stratification Mantel-Haenszel. |
| **Survie** | Modélisez le temps jusqu'à un événement : courbes de Kaplan-Meier, modèle de Cox, tables actuarielles, diagnostics des résidus et test de Schoenfeld. |
| **Prédictif** | Construisez des modèles de prédiction (Logistique, Random Forest, XGBoost), comparez les courbes ROC et identifiez le seuil optimal via l'indice de Youden. |
| **Rapport** | Prévisualisez et exportez un rapport complet de votre analyse en CSV, Excel ou HTML, avec KPIs dynamiques, graphiques et métadonnées. |
| **Prévisions** | Modélisez l'évolution temporelle d'un indicateur avec ARIMA ou ETS. Détection automatique des colonnes date, agrégation flexible (mensuelle, trimestrielle, hebdomadaire). |
| **Géolocalisation** | Visualisez vos données sur une carte interactive : détection auto lat/lon, clustering spatial K-means, heat maps et exports GeoJSON/KML. |
| **NLP** | Analysez les commentaires et textes libres de vos enquêtes : sentiments, topics LDA, nuages de mots, bigrammes. Pour les données qualitatives. |
| **Benchmarking** | Comparez vos indicateurs à une référence (groupement interne ou fichier externe) : gap analysis, percentiles, rankings et Z-scores de performance. |
