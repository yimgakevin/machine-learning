#### Module A: Spatial Autocorrelation
```r
calc_morans_i(sf_data, indicator, level)
  ├─ Moran's I global (0 = random, 1 = clustered, -1 = dispersé)
  ├─ p-value (significatif ?)
  └─ Interprétation (zones similaires côte à côte ?)

detect_spatial_clustering(sf_data, indicator)
  ├─ Identifier clusters significatifs
  └─ Mesurer l'intensité
```

#### Module B: Local Spatial Autocorrelation (LISA)
```r
calc_lisa(sf_data, indicator, level)
  ├─ Local Indicator of Spatial Association
  ├─ Identificateur pour chaque zone :
  │  ├─ HH = High-High (hotspot, voisins aussi élevés)
  │  ├─ LL = Low-Low (coldspot, voisins aussi bas)
  │  ├─ HL = High-Low (anomalie, zone isolée haute)
  │  ├─ LH = Low-High (anomalie inverse)
  │  └─ Non-sig = pas significatif
  └─ p-value pour significativité
```

#### Module C: Hotspot Detection
```r
detect_hotspots_coldspots(sf_data, indicator, threshold = 0.05)
  ├─ LISA + seuil OMS combinés
  ├─ Retour :
  │  ├─ Hotspots (HH ou HL)
  │  ├─ Coldspots (LL ou LH)
  │  ├─ Isolées (anomalies)
  │  └─ Normal (non-signif)
  └─ Priorité d'intervention par zone
```

#### Module D: Spatial Clustering (k-means spatial)
```r
cluster_spatial(sf_data, indicator, k = 5)
  ├─ K-means tenant compte de proximité géographique
  ├─ Distance = combine :
  │  ├─ Différence d'indicateur
  │  └─ Distance géographique
  └─ Zones homogènes identifiées
```

#### Module E: Spatial Narratives
```r
gen_spatial_narrative(sf_data, region_name, indicator, lisa_result)
  └─ Génère texte clinique spatial :
     "La région X (GAM=18%) est un HOTSPOT.
      - Voisins aussi affectés (HH-cluster)
      - Intervention urgente: 3 zones connexes
      - Priorité: HAUTE (classe HH significatif)
      - Stratégie: Approche régionale coordonnée"
```

#### Module F: Spatial Risk Stratification
```r
stratify_spatial_risk(sf_data, indicator, scenarios = 3)
  ├─ Combiner :
  │  ├─ Magnitude du problème
  │  ├─ Clustering spatial (isolé vs cluster)
  │  └─ Accessibilité géographique
  ├─ Output :
  │  ├─ HAUTE (clustered + sévère + accessible)
  │  ├─ MOYENNE (clusters mais moins sévère)
  │  └─ BASSE (isolé ou mineur)
  └─ Recommandations d'action par risque
```

#### Module G: Epidemiological Spread
```r
analyze_spread_pattern(sf_data, indicator, time_var = NULL)
  ├─ Pattern de propagation (si données temporelles)
  ├─ Types détectés :
  │  ├─ "Cluster expansion" (hotspot qui grandit)
  │  ├─ "Wave pattern" (propagation type épidémie)
  │  ├─ "Linear spread" (le long routes/rivières)
  │  └─ "Random" (pas de pattern)
  └─ Trajectoire prédite + zones à risque futures
```

#### Module H: Spatial Comparison Engine
```r
compare_regions_spatial(sf_data, indicator, ref_region)
  ├─ Comparer région test vs référence sur :
  │  ├─ Magnitude (valeur)
  │  ├─ Clustering (Moran's I)
  │  ├─ Hotspot dominance (% zones HH)
  │  └─ Homogénéité interne (CV spatial)
  └─ Différences statistiques + implications
```

#### Module I: Spatial Anomaly Detection
```r
detect_spatial_anomalies(sf_data, indicator)
  ├─ Identifier zones aberrantes :
  │  ├─ Valeur extrême isolée (HL ou LH significatif)
  │  ├─ Discontinuité géographique (jump brutal)
  │  ├─ Neighbors incohérents (voisins très différents)
  │  └─ Données manquantes patterned
  └─ Explication + recommandation vérification
```

#### Module J: Spatial Report Generation
```r

  ├─ Rapport Markdown complet :
  │  ├─ Résumé spatial
  │  ├─ Moran's I + interprétation
  │  ├─ Hotspots/Coldspots listés
  │  ├─ Narratifs par zone
  │  ├─ Anomalies flaggées
  │  ├─ Recommandations spatiales
  │  └─ Cartes descriptives
  └─ Exportable PDF/Markdown
```

## 🧮 ALGORITHMES CLÉS

### Moran's I
```
I = (n/S0) × Σ_i Σ_j w_ij (x_i - x̄)(x_j - x̄) / Σ_i (x_i - x̄)²

Interprétation:
- I ≈ 1 : données TRÈS clustérées (hotspots/coldspots)
- I ≈ 0 : données aléatoires
- I ≈ -1 : données DISPERSÉES (alternating)

p-value < 0.05 = significatif
```

### LISA (Local Indicator)
```
Pour chaque zone i :
  LISA_i = [(x_i - x̄) / σ²] × Σ_j w_ij (x_j - x̄)

Classification :
- HH (High-High) : zone haute, voisins hauts = HOTSPOT
- LL (Low-Low)   : zone basse, voisins bas = COLDSPOT
- HL (High-Low)  : zone haute, voisins bas = ANOMALIE
- LH (Low-High)  : zone basse, voisins hauts = ANOMALIE
- Not sig       : pas de pattern significatif
```

### Risk Stratification
```
Risk_Score = w1 × (Magnitude / Threshold) 
           + w2 × (1 if HH-cluster else 0.5)
           + w3 × (1 / Distance_to_capital)

Classes :
- HAUTE    : Risk_Score > 7
- MOYENNE  : 4 < Risk_Score ≤ 7
- BASSE    : Risk_Score ≤ 4
```
