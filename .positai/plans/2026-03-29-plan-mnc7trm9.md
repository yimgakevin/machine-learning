# Plan : Améliorer chaque module avec le dataset SMART/SENS 179 variables

## Contexte

L'application NutriAnalyse Pro v2 possède actuellement des modules d'analyse pour :
- Sécurité alimentaire (FCS, rCSI, HDDS, HHS)
- Qualité SMART (flags, digit preference, age heaping)
- Prévalences SMART (GAM/SAM pondérées)
- Z-scores OMS 2006

Avec le dictionnaire étendu à **179 variables** et le dataset SMART/SENS complet, il faut créer **8 nouveaux modules d'analyse** pour couvrir tous les modules SENS.

## Architecture

Chaque module suit le même pattern que `module_secu_alimentaire.R` :
1. **Un fichier `module_xxx.R`** — fonctions pures `calc_*()` et `plot_*()`, zéro Shiny
2. **Insertion UI** dans `app_v2_final.R` — un `tabItem(tabName="xxx")` dans la section body
3. **Insertion serveur** dans `app_v2_final.R` — un `observeEvent(input$run_xxx)` avec rendu
4. **Menu item** dans le `renderMenu()` (~ligne 3525)
5. **Traductions** dans `i18n.R`

## Modules à créer (par priorité)

### 1. `module_mortalite.R` — Mortalité SMART
- **Tab** : `mortalite` | **Icône** : `skull-crossbones`
- **Fonctions** :
  - `calc_cmr()` — CMR pondéré (décès/10 000/jour) avec IC 95%
  - `calc_u5mr()` — U5MR pondéré avec IC 95%
  - `calc_person_time()` — Person-time par ménage
  - `plot_mortality_pyramid()` — Pyramide des décès par âge/sexe
  - `plot_cause_death()` — Répartition des causes de décès
  - `render_mortality_kpi()` — Cartes KPI (CMR, U5MR, seuils d'urgence)
- **UI** : Sélecteurs colonnes + onglets Synthèse / CMR / U5MR / Causes / Pyramide

### 2. `module_iycf.R` — Alimentation du nourrisson (IYCF)
- **Tab** : `iycf` | **Icône** : `baby`
- **Fonctions** :
  - `calc_iycf_indicators()` — 8 indicateurs OMS/UNICEF 2021
  - `plot_iycf_dashboard()` — Barres horizontales des indicateurs
  - `plot_iycf_by_age()` — Pratiques par tranche d'âge
  - `plot_breastfeeding_cascade()` — Cascade allaitement
  - `render_iycf_kpi()` — Cartes KPI (EBF, MAD, MDD, MMF)
- **UI** : Sélecteurs colonnes + onglets Synthèse / Allaitement / Complémentaire / Aliments malsains

### 3. `module_anemie.R` — Anémie SENS
- **Tab** : `anemie` | **Icône** : `tint`
- **Fonctions** :
  - `calc_anemia_prevalence()` — Prévalence par sévérité avec IC
  - `calc_hb_adjusted()` — Ajustement altitude/tabac OMS
  - `plot_hb_distribution()` — Histogramme Hb avec seuils OMS
  - `plot_anemia_by_group()` — Par âge/sexe/strate
  - `render_anemia_kpi()` — Cartes KPI
- **UI** : Sélecteurs (Hb, altitude, grossesse) + onglets Synthèse / Distribution / Par groupe / IFA

### 4. `module_paludisme.R` — Paludisme & Moustiquaires SENS
- **Tab** : `paludisme` | **Icône** : `mosquito` (ou `bug`)
- **Fonctions** :
  - `calc_llin_indicators()` — Possession, accès, utilisation
  - `calc_malaria_prevalence()` — Prévalence TDR+ avec IC
  - `plot_llin_cascade()` — Cascade possession → accès → utilisation
  - `plot_malaria_by_group()` — Prévalence par strate
  - `plot_net_condition()` — État des moustiquaires
  - `render_malaria_kpi()` — Cartes KPI
- **UI** : Sélecteurs + onglets Synthèse / LLIN / TDR / Traitement

### 5. `module_wash.R` — WASH (Eau, Hygiène, Assainissement)
- **Tab** : `wash` | **Icône** : `hand-holding-droplet` (ou `tint`)
- **Fonctions** :
  - `calc_wash_indicators()` — Indicateurs JMP/Sphère
  - `classify_water_source()` — Classification améliorée/non améliorée
  - `classify_sanitation()` — Classification assainissement
  - `plot_wash_ladder()` — Échelle JMP (eau + assainissement + hygiène)
  - `plot_water_time()` — Distribution temps de collecte
  - `plot_wash_by_group()` — Par strate
  - `render_wash_kpi()` — Cartes KPI
- **UI** : Sélecteurs + onglets Synthèse / Eau / Assainissement / Hygiène

### 6. `module_menage_protection.R` — Ménage & Protection
- **Tab** : `menage` | **Icône** : `house-user`
- **Fonctions** :
  - `calc_household_profile()` — Profil démographique ménage
  - `calc_vulnerability_score()` — Score vulnérabilité composite
  - `plot_hh_composition()` — Pyramide/distribution composition
  - `plot_income_expenditure()` — Revenus vs dépenses
  - `plot_shelter_type()` — Types d'abri
  - `plot_protection_indicators()` — Indicateurs protection
  - `render_household_kpi()` — Cartes KPI
- **UI** : Onglets Composition / Économie / Abri / Protection

### 7. `module_handicap_wg.R` — Handicap (Washington Group)
- **Tab** : `handicap` | **Icône** : `wheelchair`
- **Fonctions** :
  - `calc_wg_prevalence()` — Prévalence handicap avec IC
  - `calc_wg_domains()` — Prévalence par domaine fonctionnel
  - `plot_wg_radar()` — Radar des 6 domaines
  - `plot_wg_severity()` — Distribution sévérité
  - `plot_wg_cross_nutrition()` — Croisement handicap × malnutrition
  - `render_wg_kpi()` — Cartes KPI
- **UI** : Sélecteurs 6 domaines + onglets Synthèse / Domaines / Croisements

### 8. Enrichir `module_secu_alimentaire.R` — Ajouter LCSI, FIES, MDD-W
- **Pas de nouveau tab**, extension du module existant
- **Nouvelles fonctions** :
  - `calc_lcsi()` — Classification LCSI (stress/crise/urgence)
  - `calc_fies()` — Score FIES + classification
  - `calc_mddw()` — MDD-W femmes ≥5/10 groupes
  - `plot_lcsi_stacked()` — Barres empilées LCSI
  - `plot_fies_distribution()` — Distribution FIES
- **UI** : Ajout de 3 modes supplémentaires + 3 onglets résultats dans le tabset existant
