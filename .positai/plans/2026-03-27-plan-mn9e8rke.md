# Plan de correction : NutriAnalyse Pro v2 — Bugs critiques + IA Expert

## Résumé du problème

L'application a 3 catégories de problèmes :
1. **Crashes complets** : certains clics ferment l'application (NULL non gérés, erreurs non capturées)
2. **Boutons non fonctionnels** : boutons d'action de l'IA qui ne marchent pas ou ne répondent pas
3. **IA médiocre** : l'IA actuelle se contente de rediriger vers les modules existants au lieu d'analyser réellement les données

## Architecture actuelle de l'IA (problème fondamental)

L'IA actuelle fonctionne ainsi :
- L'utilisateur pose une question → Gemini reçoit un résumé statique des données + un system prompt
- Gemini répond avec du texte + des boutons `[[ACTION:id|Texte]]` qui redirigent vers des onglets
- **L'IA ne fait AUCUNE analyse réelle** — elle redirige l'utilisateur vers les modules

Ce qu'on veut :
- L'IA reçoit les données réelles (échantillon + statistiques détaillées)
- L'IA **exécute du code R** pour analyser les données (comme un data scientist)
- L'IA retourne des résultats concrets : tableaux, graphiques, interprétations
- L'IA est capable de répondre à des questions complexes sur les données

### Phase 2 : Réécrire l'IA en mode "Expert Analyst" (nouveau chatbot_server)

C'est la partie la plus importante. On va remplacer le chatbot actuel par un système qui **analyse réellement les données**.

**Nouveau fichier : `chatbot_server_v4.R`** (remplace chatbot_server_v3.R)

Architecture du nouveau système :

```
Utilisateur pose question
    ↓
Construire un contexte RICHE (pas juste un résumé)
  - Échantillon de 20 lignes (head + tail)
  - Statistiques détaillées par colonne
  - Distribution des catégories
  - Corrélations
  - Valeurs manquantes détaillées
  - Types de données
    ↓
Gemini reçoit contexte + question + instructions R
    ↓
Gemini génère du CODE R pour répondre
    ↓
Le code R est exécuté dans un environnement sandboxé
    ↓
Les résultats (tableaux, stats, plots) sont capturés
    ↓
Gemini interprète les résultats en langage naturel
    ↓
Affichage : interprétation + tableaux + graphiques
```

**Détails de l'implémentation :**

a) **`build_rich_context(df)`** — Construit un contexte exhaustif :
   - `head(df, 10)` formaté en texte
   - `str(df)` condensé
   - Statistiques par colonne (mean, sd, quantiles, NA count, n_distinct)
   - Pour les catégorielles : `count()` avec proportions
   - Matrice de corrélation (top corrélations)
   - Détection d'indicateurs spécialisés (SMART, OMS, FCS, etc.)

b) **`generate_r_code(question, context)`** — Prompt Gemini pour générer du code R :
   - System prompt spécialisé : "Tu es un data scientist expert. Génère du code R pour répondre à cette question."
   - Le code doit utiliser tidyverse, ggplot2, et les données `df`
   - Le code doit retourner un objet `list(text = "...", plot = ggplot_object)`

c) **`safe_execute_code(code, df)`** — Exécution sandboxée :
   - Crée un environnement isolé avec `df` et les packages autorisés
   - Limite le temps d'exécution (timeout 30s)
   - Capture stdout, warnings, errors
   - Capture les plots via `recordPlot()` ou extraction ggplot
   - Liste blanche de fonctions autorisées (pas de `system()`, `file.remove()`, etc.)

d) **`interpret_results(results, question)`** — Interprétation finale :
   - Gemini reçoit les résultats bruts + la question originale
   - Génère une interprétation en français, niveau expert
   - Inclut recommandations pour la suite

e) **Rendu dans le chat** :
   - Texte de l'interprétation (markdown)
   - Tableaux intégrés (HTML via `knitr::kable()`)
   - Graphiques intégrés (rendu comme image base64 dans le chat)
   - Boutons "Approfondir" pour chaque analyse

**Nouveau fichier : `chatbot_ui_v4.R`** (remplace chatbot_ui_v3.R)
- Support pour afficher des graphiques dans les messages
- Support pour afficher des tableaux HTML dans les messages
- Amélioration du rendu markdown
- Boutons plus intuitifs
